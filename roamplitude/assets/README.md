# Roamplitude website assets

- `app-icon.png`: Roamplitude's existing app icon, copied from the `worldradio` app repository and resized for the website.
- `synthwave-globe.jpg`: original AI-generated artwork created for this landing page, compressed for web delivery. It is an illustration, not an app screenshot.
- `fonts/space-grotesk.woff2`: self-hosted Latin variable font from Google Fonts, weights 400–700. See `fonts/OFL.txt` for its SIL Open Font License.

All assets are served from this repository. The Roamplitude pages do not load third-party scripts, fonts, analytics, or audio streams.

The custom domain uses Cloudflare in front of GitHub Pages. `email_off` comments around contact links preserve readable email addresses and working `mailto:` links without requiring Cloudflare's email-decoding JavaScript.
